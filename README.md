# Chakra–Endocrine Text Analysis

## Introduction

The aim of this project is to examine whether the traditional chakra system corresponds uniquely to specific endocrine glands or whether conceptual relationships are distributed across multiple glands.

To investigate this question, cultural chakra literature and biomedical endocrine literature were analyzed using computational text analysis techniques. The project integrates natural language processing methods, topic modeling, semantic similarity analysis, and statistical testing.

The analysis pipeline includes:

- Extracting chakra-specific sections from cultural texts
- Performing topic modeling using Latent Dirichlet Allocation (LDA)
- Measuring semantic similarity between chakra texts and endocrine gland texts
- Comparing predicted chakra–gland pairings with all possible pairings
- Performing permutation testing to evaluate specificity
- Visualizing similarity relationships using a heatmap

The goal of this repository is to provide a **fully reproducible computational workflow** for the analysis performed in the thesis.

# Project Directory

The project folder should contain the following directories:

```
chakra_thesis_project
│
├── chakra_papers
├── endocrine_papers
├── chakra_split
├── scripts
└── results
```

chakra_papers contains cultural texts describing the chakra system.

endocrine_papers contains biomedical papers describing endocrine glands.

chakra_split contains chakra-specific text segments generated during preprocessing.

scripts contains the Python programs used for the computational analysis.

results contains the outputs generated by the scripts.

---

# Step 1 — Split Chakra Texts

The first step is to extract chakra-specific sections from the cultural chakra texts.

This script scans the chakra literature and separates text corresponding to individual chakras.

Run the following command:

```bash
python3 scripts/split_chakras.py
```

Output:

```
chakra_split/
```

This directory will contain separate text files for:

- root chakra
- sacral chakra
- solar plexus chakra
- heart chakra
- throat chakra
- third eye chakra

These files serve as the chakra-specific corpora used in the remainder of the analysis.

---

# Step 2 — Topic Modeling Analysis

Next, topic modeling is performed using Latent Dirichlet Allocation (LDA).

This step identifies prominent semantic themes across the combined corpus of chakra and endocrine texts.

Run the following command:

```bash
python3 scripts/run_analysis.py
```

Output:

```
results/lda_topics.txt
```

This file contains the topics identified by the LDA model and the most representative words associated with each topic.

---

# Step 3 — Pairwise Topic Modeling

Next, pairwise topic comparisons are performed between chakra corpora and endocrine gland corpora.

This step allows exploration of thematic similarities between the two sets of texts.

Run the following command:

```bash
python3 scripts/pairwise_lda.py
```

This script compares topic distributions between chakra texts and endocrine gland texts.

---

# Step 4 — Cosine Similarity Analysis

Next, cosine similarity is calculated between each chakra corpus and its traditionally proposed endocrine gland.

Cosine similarity measures semantic similarity between two text corpora.

Examples of predicted chakra–gland pairings include:

Root chakra → Adrenal glands  
Sacral chakra → Gonads  
Solar plexus chakra → Pancreas  
Heart chakra → Thymus  
Throat chakra → Thyroid  
Third eye chakra → Pineal gland  

Run the following command:

```bash
python3 scripts/cosine_similarity_analysis.py
```

Output:

```
results/cosine_similarity_results.txt
```

This file contains cosine similarity scores for the predicted chakra–gland pairings.

---

# Step 5 — Full Chakra × Gland Similarity Matrix

In order to compare predicted pairings with all possible pairings, cosine similarity is calculated between every chakra corpus and every endocrine gland corpus.

Run the following command:

```bash
python3 scripts/all_chakra_all_gland_cosine.py
```

This script produces a similarity matrix containing all chakra–gland combinations.

This allows direct comparison between predicted pairings and alternative pairings.

---

# Step 6 — Specificity Test (Permutation Test)

To evaluate whether the traditional chakra–gland pairings show stronger similarity than random assignments, a permutation-based specificity test is performed.

This analysis calculates:

- Mean similarity of predicted chakra–gland pairs
- Mean similarity of all other combinations
- The difference between these values
- A permutation-test p-value

Run the following command:

```bash
python3 scripts/specificity_test.py
```

Output:

```
results/specificity_test_results.txt
```

This file contains the statistical results used to evaluate whether the predicted mappings show stronger correspondence than random assignments.

---

# Step 7 — Heatmap Visualization

Finally, the chakra × gland similarity matrix is visualized using a heatmap.

The heatmap displays:

- Chakras on the vertical axis
- Endocrine glands on the horizontal axis
- Color intensity representing cosine similarity values

Run the following command:

```bash
python3 scripts/make_heatmap.py
```

Output:

```
results/chakra_gland_heatmap.png
```

The heatmap provides a visual representation of similarity relationships between chakra texts and endocrine gland texts.
